# HabitShield 🛡️

### A Security-Focused Application

HabitShield is a security-focused application designed to help users identify potentially sensitive information and suspicious messages through multiple scanning features.

## Features

- **Dashboard:** Displays scan statistics, detected threats and recent activity.
- **Screenshot Scanner:** Detects sensitive information in uploaded images.
- **File Hash Scanner:** Generates SHA-256 fingerprints for uploaded files.
- **SMS Phishing Analyzer:** Analyses messages and classifies them as safe, suspicious or potentially fraudulent.
- **Activity Log:** Maintains a history of scans, results and timestamps.

## Tech Stack

- TypeScript
- CSS
- HTML

## Project Purpose

The project explores practical applications of programming and security concepts through an interactive scanning interface.
